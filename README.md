# The World in One Day — 21 November 2026

A newspaper front page summing up the world's news of Saturday,
21 November 2026, drawn entirely with PIL and DejaVu fonts.

Lead: Russian missiles land in Poland during the huge overnight
barrage on Ukraine. Also: COP31 runs into overtime in Antalya,
Wall Street slides into correction, the FBI database is hacked,
Bayer's $7.25bn Roundup settlement is approved, and GTA VI takes
$3.79bn in a day.

`main.py` (Python 3.13, standard library only) copies `entry.png`
to the output directory, so both runs produce identical bytes.
`draw_frontpage.py` draws the front page from scratch.
